PRACTICAL 11 : Java word count commands

============================================================================================

Steps to Run Hadoop MapReduce WordCount Program on Ubuntu
1. Create Java File

Open terminal and create the file:

nano WordCount.java

Paste your complete Java code and save:

Press CTRL + O → Enter
Press CTRL + X
2. Create Input File
mkdir input
nano input/data.txt

Example text:

hello world
hello hadoop
world hadoop

Save and exit.

3. Compile the Java Program

Move to the folder where WordCount.java is saved.

Run:

mkdir wc_classes

Now compile:

javac -classpath $(hadoop classpath) -d wc_classes WordCount.java
4. Create JAR File
jar -cvf wordcount.jar -C wc_classes/ .
5. Remove Old Output Folder (Important)
rm -rf output
6. Run the Hadoop Program
hadoop jar wordcount.jar WordCount input output

Where:

input → input folder
output → output folder generated by Hadoop
7. View Output
cat output/part-r-00000

============================================================================================

PRACTICAL 12 : Map and Reduce commands

============================================================================================


1. Create Java File

Open terminal:

nano LogProcessor.java

Paste your complete Java code and save:

CTRL + O → Enter
CTRL + X
2. Create Input Folder and Log File
mkdir logs
nano logs/systemlog.txt

Add sample log data:

2026-05-09 10:00:00 INFO System started
2026-05-09 10:01:00 WARN Low memory
2026-05-09 10:02:00 ERROR Disk failure
2026-05-09 10:03:00 INFO User login
2026-05-09 10:04:00 ERROR Network issue

Save and exit.

3. Create Classes Folder
mkdir log_classes
4. Compile Java Program
javac -classpath $(hadoop classpath) -d log_classes LogProcessor.java
5. Create JAR File
jar -cvf logprocessor.jar -C log_classes/ .
6. Remove Old Output Folder
rm -rf logoutput
7. Run Hadoop MapReduce Program
hadoop jar logprocessor.jar LogProcessor logs logoutput

Where:

logs → input folder
logoutput → output folder
8. View Result
cat logoutput/part-r-00000

=================================================
